| Function       | Kya check karta hai?         | Example                |
| -------------- | ---------------------------- | ---------------------- |
| `isdigit(ch)`  | `0–9` digit hai?             | `isdigit('5')` → true  |
| `isalpha(ch)`  | Alphabet hai?                | `isalpha('A')` → true  |
| `isalnum(ch)`  | Alphabet **ya** digit?       | `isalnum('7')` → true  |
| `islower(ch)`  | Lowercase hai?               | `islower('a')` → true  |
| `isupper(ch)`  | Uppercase hai?               | `isupper('A')` → true  |
| `isspace(ch)`  | Space/whitespace hai?        | `isspace(' ')` → true  |
| `ispunct(ch)`  | Punctuation character hai?   | `ispunct('!')` → true  |
| `isxdigit(ch)` | Hexadecimal digit hai?       | `isxdigit('F')` → true |
| `isprint(ch)`  | Printable character hai?     | `isprint('A')` → true  |
| `isgraph(ch)`  | Printable but **space nahi** | `isgraph('A')` → true  |
| `iscntrl(ch)`  | Control character hai?       | `iscntrl('\n')` → true |
| `isblank(ch)`  | Space/tab hai?               | `isblank(' ')` → true  |


⭐ Placement/DSA ke liye sabse important

Inko pakka yaad karo:

isdigit(ch)   // digit?
isalpha(ch)   // alphabet?
isalnum(ch)   // alphabet OR digit?
islower(ch)   // lowercase?
isupper(ch)   // uppercase?
isspace(ch)   // whitespace?

🔄 Character Conversion Functions:::::
Ye bhi bahut useful hain:
tolower(ch)
toupper(ch)

Commonly used combination

String ko lowercase mein convert karna::::

for (char &ch : s) {
    ch = tolower(ch);
}

String ko uppercase mein convert karna:::::

for (char &ch : s) {
    ch = toupper(ch);
}
🧠 Ekdum


🧠 Ekdum short cheat sheet
isdigit  → 0-9
isalpha  → A-Z / a-z
isalnum  → alphabet + digit
islower  → a-z
isupper  → A-Z
isspace  → space/tab/newline
ispunct  → ! @ # $ % ...
isxdigit → 0-9, A-F, a-f

tolower  → lowercase
toupper  → uppercase
